# Commercial Quality Gate

A product can ship only when every gate below is PASS.

1. Concept — clear buyer/use case and no dependency on protected characters or brands.
2. Artwork — original composition, clean typography, balanced hierarchy, transparent print-safe background, no artifacts.
3. Files — SVG opens correctly, PNG is high resolution, file names are marketplace-safe, no accidental hidden objects.
4. Visual QA — realistic mockup, light and dark garment previews, readable thumbnail, details survive downscaling.
5. Packaging — ZIP contains buyer-facing files only, README explains contents, license is explicit.
6. Listing — accurate title, DIGITAL DOWNLOAD disclosure, formats/dimensions stated, no misleading physical-product claims.
7. IP — original artwork, no copied competitor artwork, no brand/logo references, phrase collision search documented.
8. Marketplace — current file-size/format/listing requirements verified.
9. Final acceptance — assets inspected manually, ZIP unpacked, design visually tested, release evidence stored.

Only all PASS = 100%.
