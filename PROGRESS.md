## Quality gate

A design is not final merely because the SVG exists. It must pass:
1. visual/thumbnail review;
2. SVG structure review;
3. PNG 4500×5400 transparent render;
4. print-safety review;
5. originality/IP review;
6. mockup review using the actual final asset;
7. final human-style acceptance.

* Existing PNG pipeline is operational, but any changed master must be regenerated and revalidated before it can be called final.

No artificial 100% claims.
