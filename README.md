# MINI — Printable Focus Planner

A small, polished, local-first printable planner designed as a standalone digital product.

## Product goal

Create a useful $1–$3 digital product that is fast to understand, works without an account or backend, is mobile-friendly, and prints cleanly to A4/Letter.

## Current scope

- Daily focus planning
- Top 3 priorities
- Task list
- Notes
- Habit checkboxes
- Progress indicator
- Theme selection
- Local save in the browser
- Print / Save as PDF
- English / Russian / Italian UI
- Responsive mobile layout
- No backend and no account required

## Quality rule

A green automated test is not considered commercial readiness by itself. Before release, the production build must be manually and automatically checked for functionality, print layout, mobile layout, localization, persistence, and regression.
