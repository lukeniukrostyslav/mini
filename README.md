# MINI — Original Digital Print Studio

MINI is a commercial digital-print product line focused on small, original, low-price downloadable designs for marketplaces.

## Production format
- original vector master
- transparent high-resolution PNG
- print specification
- listing copy
- preview/mockup assets
- buyer instructions
- QA evidence
- release manifest

## Commercial rule
No copied artwork, logos, characters, celebrity likenesses, or unverified protected phrases. Every product must pass an originality/IP review before release.

## Quality rule
A green automated test is never enough for release. A product is 100% only after asset, print, visual, packaging, metadata, marketplace, and final human-style QA gates are verified.
